# Desktop Buddy project instructions

## Learn while building

For every completed change batch, give a short CS learning summary: what changed and why, one underlying concept, a link to key code, verification/measurement, and one optional practice exercise. Keep it concise and do not delay delivery. Detailed rule: [.cursor/rules/learning-summary.mdc](.cursor/rules/learning-summary.mdc).

## Tool and popup latency

Keep local commands independent of AI/network. Use lightweight entry bundles for compact surfaces, preserve focus during preparation, and briefly reuse hidden windows with bounded idle cleanup. Never capture a screen or submit a provider prompt before explicit submission. Measure cold and warm paths separately; distinguish measured results from targets. Apply this policy to future tools and popups too.
